# Contribute to Geode
The [Apache Geode community](https://projects.apache.org/committee.html?geode) welcomes contributors interested in helping improve Geode.
Our community builds everything from this website to the Geode code to documentation and best practices information.

We especially welcome additions and corrections to the documentation, wiki, and website to improve the user experience.
Bug reports and fixes and additions to the Apache Geode code are welcome. Helping users learn best practices also earns good karma in our community.
