# Contribute to Geode
The Apache Geode community builds and maintains all aspects of the Geode project—from this website to the Geode application code to documentation and best practices information—and we encourage you to get involved.

We welcome all forms of contribution.
We *especially* welcome additions and corrections to the documentation, wiki, and website that improve the overall experience of using Geode.
Filing bug reports and offering fixes to the Apache Geode code are also excellent ways to contribute to the project.

## How to contribute

- Find a big to fix by reviewing open issues in the [issue tracker](https://issues.apache.org/jira/projects/GEODE/issues)
- Check [current pull requests](https://github.com/apache/geode/pulls) and help review them
- Review documentation on [the Geode wiki](https://cwiki.apache.org/confluence/display/GEODE/) and update it
- Propose changes to the [Geode project website](https://github.com/apache/geode-site)

For complete contribution instructions, see [How to Contribute](https://cwiki.apache.org/confluence/display/GEODE/How+to+Contribute) in the Geode wiki.
